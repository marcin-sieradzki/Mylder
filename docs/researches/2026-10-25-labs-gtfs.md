# The Labs GTFS as Mylder's timetable: what it holds and what it weighs

Research for Mylder, 2026-10-25. Ticket: Whether Mylder needs a timetable, and where it lives (#17).

Research caveat: this environment could not open labs.rejseplanen.dk, labs.rejseplan.dk, www.rejseplanen.info, transit.land, mobilitydatabase.org, docs.github.com, vercel.com or gtfs.org. Facts from those pages come from quoted search snippets, marked "(snippet)". Public GitHub files were read in full. One primary file was read in full: a copy of the Labs GTFS itself, taken from the Mobility Database's public mirror of its latest download (see "The sample feed"). Each claim carries a label:

- **Confirmed**: in the owner's own words (a snippet of the primary page), or measured in the sample feed.
- **Reported**: from a secondary source, such as another project's notes, a catalogue or a news story.
- **Unconfirmed**: no source found, or sources disagree.

## Short answers

**Access.** Rejseplan Labs offers a static GTFS, "som opdateres ca. hver 14. dag", with no realtime data, and keeps an archive back to 2025-12-15 (Confirmed, snippet [1]). The Labs overview lists it as free on request for non-commercial use, with at least two months of timetable ahead (Confirmed, snippet [2]). Access is requested through a Labs contact form; once approved you get an account with a password (Confirmed, snippet [4]). The producer URL is `https://www.rejseplanen.info/labs/GTFS.zip` (Reported [5][7]). The Mobility Database catalogue records that URL with `authentication_type` 0, meaning no credentials, and both the Mobility Database and Transitland fetch it on a schedule (Reported [5][7]). Whether a plain download works today, or whether the account's password is needed, is Unconfirmed: the maintainer tests it with one request once the account exists.

**Licence.** Rejseplan's data is under CC BY 4.0 by the Labs guidelines (Confirmed, snippet [3]); the GTFS is listed as CC BY 4.0 by Transitland and a national catalogue (Reported [7][16]). The 2017 wording was CC BY-ND (Reported [17]). The feed's `attributions.txt` names "Rejseplanen" as producer with `https://www.rejseplanen.dk` (Confirmed, sample feed [6]). The static data may be used commercially; only the API needs an agreement for that (Confirmed, snippet [3]).

**Cadence.** "Ca. hver 14. dag" (Confirmed [1]). The Mobility Database's download history shows new versions every one to two weeks (Reported [5]). One bridge calls it "the weekly timetable" (Reported [8]). Each release covers about 12 weeks: the 2026-06-01 release runs 2026-06-01 to 2026-08-26 (Confirmed [6]); the May 2026 release ran 2026-05-18 to 2026-08-12 and the October 2026 one runs to 2026-12-30 (Reported [5]).

**Size.** The 2026-06-01 release is 64.4 MB zipped and 437 MB unzipped (Confirmed [6]); the Mobility Database lists the May 2026 release at 63.7 MB and 428.4 MB (Reported [5]). Earlier releases were 48 to 56 MB zipped (Reported [5]).

**Files.** `agency`, `attributions`, `calendar`, `calendar_dates`, `frequencies`, `routes`, `shapes`, `stops`, `stop_times`, `transfers`, `trips`. No `feed_info.txt`, so no feed version inside the file (Confirmed [6]). `shapes.txt` is present and every trip has a `shape_id` (Confirmed [6]). `frequencies.txt` is a header only (Confirmed [6]), as in every archived version (Reported [7]). `stop_times.txt` has no `timepoint` and no `shape_dist_traveled` column (Confirmed [6]).

**Coverage of Copenhagen's modes.** Metro (Metroselskabet, `route_type` 1, lines M1 to M4), S-tog (DSB S-tog, `route_type` 109, lines A, B, Bx, C, E, F, H), Hovedstadens Letbane (`route_type` 0, line "L"), and the harbour buses (Movia, `route_type` 4, lines 991, 992, 993) are all in the feed (Confirmed [6]). Metro trips are single trips with clock times, not frequencies (Confirmed [6]).

**Ids.** `stop_id` is a 12-digit zero-padded number; `000008600626` is København H, where the API says `8600626` (Confirmed [6], Reported [8]). `trip_id` is a 9-digit number, unrelated to anything in the API (Confirmed [6]). The bridge that joins the API to this feed re-matches after every reload because trip ids change with it (Reported [8]). `trip_short_name` carries the train number for S-tog and DSB trains, such as `625222` for an S-tog Bx; the API's product `num` has the same shape (Confirmed [6] for the GTFS, Reported [16] for the API); whether they are equal is Unconfirmed.

**NeTEx.** Comes only from Dataudveksleren, after a login or a service account, and its licence was changed to CC BY-ND 3.0 in 2023 (Reported [16]). Dataudveksleren is dropped, so NeTEx is ruled out; the GTFS has everything Mylder needs, including shapes.

## The sample feed

The Mobility Database keeps a public copy of its latest download of every catalogued feed. For this feed it is `https://storage.googleapis.com/storage/v1/b/mdb-latest/o/dk-unknown-rejseplanen-gtfs-1292.zip?alt=media` (Reported [5], URL from the catalogue CSV). The copy read here has SHA-256 `4f2b8119f3dfa34ea89863353cd4980498fac8c75b37b293747f71ce5d3e3a62`, 64,408,716 bytes; its files are dated 2026-06-01 and its calendar runs 2026-06-01 to 2026-08-26. It is one release, four months old; the numbers below will drift, and the full light rail (opened 2026-08-22, Reported [18]) is not yet in it.

Transitland's archived versions agree on the order of magnitude: `stop_times.txt` 3.4 to 4.8 million rows, `shapes.txt` 3.5 to 3.9 million, `trips.txt` 163,860 to 181,763, `stops.txt` about 37,000, 1,535 to 1,760 routes, 23 to 39 agencies, over 2022 to 2025 (Reported [7]). Route types beyond the basic set: 109 is S-tog (suburban railway), 700 is Movia's S-buses (150S to 600S), 715 is demand-responsive buses in Jutland. `route_color` is empty for every route looked at, including the Metro, so line colours cannot come from the feed.

Stops: because there is no `parent_station`, one Stop in Mylder's sense is several rows. Nørreport is seven rows: `000008600646` "Nørreport St." (trains), `000008603307` "Nørreport St. (Metro)" and five bus rows named "Nørreport St. (Nørre Voldgade)" or "(Frederiksborggade)". `transfers.txt` links them (type 2, 120 to 420 s). Stripping the bracketed part of the name groups the 4,329 rows inside the Copenhagen box into 1,977 names, of which 1,606 cover more than one row.

"Underway" counts every trip with a call in the box between its first departure and last arrival, including the part of its run outside the box, so the number with a position inside the box at the weekday peak is lower than 1,011, but close to `journeyPos`'s cap of 1,000 journeys. The browser's start load for this box is about 0.4 MB gzipped.

Join checks on the Tuesday: the key (first stop, first departure minute, last stop) is shared by 674 trips, almost all M3, which is a ring whose two directions leave København H at the same minute; adding the line name leaves 626 (M3's two directions, plus lines 71, 72 and 74 that leave Frederiksberg Rådhus together). Adding the direction, or the second stop, separates them. Only two trips are exact duplicates (same stops and times), which matches the bridge's 43 ambiguous trips nationally (Reported [8]).

Metro headways from the planned times: M1 and M2 every 240 s at Vanløse 08:00 to 09:00 and every 360 s at 22:00; M3 every 180 s at København H in the morning and 240 s at 22:00; M4 180 s in the morning (with two 240 s gaps). So "every 3 min" can be worked out from the planned times for any hour. A news report says the Metro does not run to the minutes Rejseplanen shows, even when nothing is wrong (Reported [15]).

The light rail in the June feed is line "L" with 12 calls per trip, 236 trips a day: the southern section. The harbour buses: 991 and 992 ran 27 trips each with 10 or 11 calls; 993 had no trips on that Tuesday.

The script that produced these numbers ran in 33 s on four cores in Python, including the simplification; the download is 64 MB. A job that does this once a day is cheap.

## Where a job can run, and where its output can live

### GitHub Actions

- GitHub Free: 2,000 minutes a month and 500 MB of artifact storage for private repositories; standard runners are free in public repositories; minutes reset monthly, storage does not (Confirmed, snippet [10a]).
- In a public repository, scheduled workflows are disabled automatically after 60 days without repository activity; a forked repository's schedules are off by default (Confirmed, snippet [10b]). Whether the workflow's own commits count as activity is Unconfirmed.
- `schedule` runs only from the default branch; scheduled runs can be delayed at busy times, especially on the hour, and may be dropped under heavy load (Confirmed, snippet [10c]).
- Release assets: 2 GiB per file; total release size and download bandwidth are not capped in the sources found (Reported [11]).

### Vercel Hobby

- Fast Data Transfer: 100 GB a month, measured on every request and response between the CDN and the visitor, static files included; no extra usage can be bought (Confirmed, snippet [12a]). Whether a CDN cache hit is counted differently is Unconfirmed; assume it counts.
- Deployments: 100 a day, 6,000 build minutes a month, one build at a time, 45 minutes per build (Confirmed, snippet [12b]).
- Cron: at most once a day, with hourly precision, so a `0 1 * * *` job fires between 01:00 and 01:59; 100 crons a project (Confirmed, snippet [12c]). Functions are cut at 300 s (earlier research). Not a place for a 64 MB download and a 437 MB unzip.
- Blob: 1 GB storage, 10 GB data transfer, 10,000 simple and 2,000 advanced operations a month; over a limit, Blob access stops until 30 days have passed (Confirmed, snippet [12d]).
- Deploy hooks: a URL that takes a POST and rebuilds one branch, no token needed (Confirmed, snippet [12e]).
- Environment variables: sensitive ones are stored unreadably and are available only in Production and Preview, never Development; `vercel env` makes Production and Preview values sensitive by default (Confirmed, snippet [12f]). Values prefixed `NEXT_PUBLIC_` are inlined into the browser bundle by Next.js, so the key must never carry that prefix (Next.js convention, earlier research).
- Previews: every push to a connected repository builds a deployment unless the Ignored Build Step says otherwise (Confirmed, snippet [12g]). Vercel Authentication with Standard Protection is available on Hobby and gates preview URLs while the production domain stays public (Confirmed, snippet [12h]).

### Other free hosts for static files

- jsDelivr serves files from public GitHub repositories and releases with no bandwidth cap (Reported [13]); a 50 MB file limit is reported by a third party (Unconfirmed). It needs a public repository.
- The Mobility Database mirror above is a third party's copy of the input, not a home for the output.
